IMG Per-frame video pipeline
Python · OpenCV 2026

Video Processing Pipeline

I built the video half of a CSC2014 computer vision assignment: a pipeline that reads four videos frame by frame, runs five processing stages on every frame, and writes out a new video. Only OpenCV, NumPy and Matplotlib, no machine learning libraries.

PythonOpenCVNumPyMatplotlib
  • Day / night detection: each frame is converted to HSV and its value channel averaged, which gives one number for scene brightness independent of colour. Below a threshold the frame counts as night and gets brightened by a linear point operation, adding a constant to every pixel so brightness rises without touching contrast.
  • Face blurring: a Haar cascade locates camera-facing faces and each region is anonymised with Gaussian blur, which softens eyes, nose and mouth into a natural gradient rather than leaving a hard censor block.
  • Overlay, watermark, end screen: a talking-head video composited picture-in-picture and looped so it never runs out before the main video does; watermarks keyed off their own black background so an arbitrarily shaped logo works without an alpha channel; the end screen resized and written after the final frame as its own segment.
  • The decision I would defend: Haar cascades over a deep learning detector. They are lighter and fast enough to run on every frame of four separate videos, and still reliable for faces pointed at the camera. The right trade for this workload.
  • Team: a three person group project. I owned Task A, the video pipeline above; my teammates built Task B, paragraph extraction from scanned pages.

Java · OOP 2024

Pokémon Battle Game Engine

A turn based battle engine built in Java to put object oriented design to work properly, rather than just to pass the module.

JavaOOPPolymorphism
  • What it does: inventory system, weather based elemental damage multipliers, conditional mystery box drops, an in-game shop economy, and an evolution algorithm triggered by wins.
  • The design: built on polymorphism, composition and encapsulation so that adding a new Pokémon type or a new weather effect does not mean editing the battle logic.
  • What was hard: the damage calculation stacked type advantage, weather and items together. Getting that into one readable method instead of a pile of nested if statements took several rewrites.

Online Shopping Database System

A relational database for an e-commerce shop, built in Microsoft Access with proper keys and table relationships rather than one giant table.

Microsoft AccessSQLERD
  • What it does: manages customers, products, orders and order items for an online shop, with queries and forms over the top.
